# Sana AI Technical Bible

Welcome to the **Sana AI Technical Bible**. This handbook was created to be your ultimate reference for project reviews, vivas, placements, and understanding the core architecture of everything you have built in Sana AI.

Instead of a single overwhelming 150-page document, this handbook is split into 6 detailed chapters that cover all 21 parts of your request. These files are saved directly in your project under `docs/sana-technical-bible/` so you can reference them alongside your code forever.

## How to Use This Bible
If an interviewer asks, *"Did you really build this?"*, your defense relies on understanding the "Why" and "Where".
1. **Read Chapter 6 first** to see the high-level questions you will face.
2. **Follow the 8-Week Roadmap** to actively trace the concepts in your own codebase rather than just reading about them.
3. Keep these markdown files open in your IDE while you review your code!
